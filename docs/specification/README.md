## 版と適合性

プロトコル識別子は`commons-identity/1`です。現時点の文書とCI-Core profileはDeveloper Previewであり、参照実装は実験的・未監査です。仕様の要求を実装したと主張するだけでは適合になりません。公開された適合試験、第三者監査、独立実装との相互運用試験が必要です。

誤植を超える意味変更はADRとCHANGELOGへ記録します。安定版発行後の破壊的変更は、新しいプロトコル識別子を必要とします。
